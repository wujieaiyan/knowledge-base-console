## 1. 端到端验收场景

### A. 建库到可检索（P0）

**A1 创建知识库**

- **Given** 张三具备建库权限，属于人力资源部
- **When** 依次填写名称、简介，保留默认解析/切片/检索配置并提交
- **Then**
  - 返回 `201`，知识库状态为可用，配置版本为 v1，张三为 owner
  - 根目录“全部知识”存在
  - 列表页“我的可维护”出现该知识库，卡片字段完整
  - 重复提交同一幂等键不会产生第二个知识库

**A2 首批文档入库**

- **Given** 知识库已创建，解析配置包含 PDF/DOCX
- **When** 上传 3 份文档并选择目录
- **Then**
  - 接口立即返回 3 个 `documentId` 与任务 ID
  - 任务中心依次出现排队/运行/成功状态
  - 文档最终为“已就绪”，切片数 > 0
  - 列表计数、概览指标同步更新
  - 检索测试可命中新文档

### B. 权限视图（P0）

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| B1 | 用户对 A 库 reader、B 库 editor | “可访问”含 A/B，“可维护”仅 B |
| B2 | 用户无任何授权 | 两个 Tab 均为空，接口不返回他人知识库 |
| B3 | 直接访问无权知识库 URL | 返回 404 页面，不泄露名称 |
| B4 | editor 调用保存配置接口 | 403，配置不变 |
| B5 | 部门授权新增成员 | 新成员即时获得对应角色 |
| B6 | 移除唯一 owner | 400 `KB_40009`，成员不变 |
| B7 | 部门继承成员尝试单独移除 | 400 `KB_40010`，提示调整部门授权 |
| B8 | 个人 editor + 部门 reader | 有效角色 editor，可维护 |

### C. 解析引擎（P0）

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| C1 | PDF 自动判定（文本版） | 走原生提取，保留页码与 bbox |
| C2 | PDF 自动判定（扫描版） | 走 OCR，引用含页码/坐标 |
| C3 | PDF 选原生提取但为扫描件 | 任务失败 `KB_42202`，提示启用 OCR |
| C4 | DOCX 保留标题与表格 | 切片元数据含标题路径，表格完整 |
| C5 | XLSX 多工作表 | 每表按表头 + 行分组，表头重复 |
| C6 | Markdown 代码块 | 代码块不被切断，标题树正确 |
| C7 | 取消勾选所有文档类型 | 下一步被阻断 |
| C8 | 非 PDF 类型选 OCR 但未开内嵌图片 | 配置校验失败，定位字段 |
| C9 | 加密 PDF | 失败 `KB_42201`，提示移除密码 |
| C10 | OCR 服务不可用 | 任务失败 `KB_42203`，可重试，不丢文件 |

### D. 切片策略（P0/P1）

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| D1 | 默认切分 512/64 | 块大小 P99 ≤ 614（约 1.2×），无句子中间截断 |
| D2 | 重叠参数 > max/2 | 保存被阻断 |
| D3 | 按行切分 + 短行合并 | 连续短行合并，不产生大量碎片 |
| D4 | 父子切分 | 子块可检索，命中后返回父块；父块不单独参与相似度 |
| D5 | 父子参数子 > 父 | 保存被阻断 |
| D6 | 标题增强 | 每块含 `title_path`，超长路径按规则截断 |
| D7 | 自定义分隔符非法正则 | 保存被阻断，定位字段 |
| D8 | 自定义分隔符灾难性回溯 | 100 ms 内拒绝，不拖垮服务 |
| D9 | 表格超过 1.5×max | 按行拆分且每块重复表头 |
| D10 | 切片预览（P1） | 返回前 20 条，不落库、不建任务 |

### E. 文档与任务（P0）

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| E1 | 上传不支持格式 | 前端拦截，服务端二次校验 `KB_40003` |
| E2 | 文件 > 100 MB | `KB_40004`，不落库 |
| E3 | 同库重复文件 | 返回 `duplicated=true`，不新增文档 |
| E4 | 批量上传 50 个 | 逐项返回，单条失败不影响其他 |
| E5 | 解析失败 | 文档状态失败，错误码/原因可查，任务可重试 |
| E6 | 重试成功 | 文档就绪，无重复切片 |
| E7 | 停用文档 | 检索不再返回该文档 |
| E8 | 删除文档 | 状态删除中 → 已删除；检索立即不可见；异步清理完成 |
| E9 | 同文档重复触发重建 | 返回 409 + 运行中任务 ID，不产生并行任务 |
| E10 | 取消运行中任务 | 取消中 → 已取消；无残留切片/向量 |
| E11 | 任务列表筛选 | 类型/状态/时间/关键字组合正确 |
| E12 | 任务超过 30 天 | 列表不可见，审计仍可查 |

### F. 配置变更与重建（P0）

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| F1 | 仅修改阈值/TopK | 保存新版本，不触发重建，检索立即使用新值 |
| F2 | 修改切片参数选择“仅保存” | 新版本生效于后续任务，存量不变 |
| F3 | 修改切片参数选择“全量重建” | 创建重建任务，成功后索引切换 |
| F4 | 索引策略变更 | 强制二次确认，仅允许保存或全量重建 |
| F5 | 在跑任务期间改配置 | 在跑任务仍用旧版本，新任务用新版本 |
| F6 | 重建部分失败 | 任务失败并返回失败清单，可仅重试失败文档（P1） |
| F7 | 重建中检索 | 继续使用旧代索引，不中断 |
| F8 | 并发保存配置（If-Match 不匹配） | 409，提示刷新，不覆盖他人修改 |

### H. 检索与引用（P0/P1）

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| H1 | 混合检索命中 | 返回切片、召回分、精排分 |
| H2 | 关闭混合检索 | 仅向量召回，分数字段符合约定 |
| H3 | 阈值 0.9 无命中 | `hits=[]`、`noAnswer=true`，无引用 |
| H4 | 关闭溯源 | 不返回 citation |
| H5 | 溯源粒度 PAGE | 返回页码 + bbox |
| H6 | 溯源粒度 PARAGRAPH | 返回段落/字符区间 |
| H7 | XLSX 引用 | 返回 sheetName + 行范围 |
| H8 | 精排服务不可用 | 降级为融合分数，结果可用并标记降级 |
| H9 | 嵌入服务不可用（检索） | 走 BM25，结果可用并标记降级 |
| H10 | 无权用户检索 | 404/403，不返回任何切片 |
| H11 | 停用/删除文档切片 | 不出现在结果中 |
| H12 | 检索测试 | 使用已保存配置；未保存修改不生效并提示 |
| H13 | Elasticsearch 不可用 | 自动回退本地 H2，`retrievalEngine=LOCAL`，结果可用 |
| H14 | Ollama 不可用/模型缺失/超时 | 引用照常返回，`answer=null`、`llmUsed=false`、`llmError` 可读 |
| H15 | 重解析文档 | ES 中该文档切片被替换，索引总数与 H2 一致，无旧切片残留 |

### I. 安全与异常（P0）

| 编号 | 场景 | 预期 |
| --- | --- | --- |

| I3 | 文档内容含脚本/HTML | 引用渲染转义，不执行 |

| I8 | 解析/索引服务不可用 | 任务排队或失败可重试，不丢元数据 |

## 2. 测试矩阵

### 2.1 文档类型 × 解析方式

| 类型 \ 方式 | NATIVE | OCR | AUTO |
| --- | --- | --- | --- |
| PDF 文本版 | ✓ | ✓（效果下降） | ✓ 推荐 |

| DOCX | ✓ | 仅内嵌图片 | ✓ |

### 2.2 切片策略 × 文档类型

| 策略 \ 类型 | PDF | DOCX | XLSX | MD |
| --- | --- | --- | --- | --- |
| 默认 | ✓ | ✓ | ✓ | ✓ |
| 按行 | ✓ | ✓ | ✓ 优先 | ✓ |
| 父子 | ✓ | ✓ | △ 不推荐 | ✓ |
| 标题增强 | ✓ | ✓ 推荐 | △ | ✓ 推荐 |
| 自定义 | ✓ | ✓ | △ | ✓ |

### 2.3 角色 × 操作

覆盖 PRD 权限矩阵全部组合，重点用例：editor 保存配置、reader 上传、admin 删除知识库、owner 转让、平台管理员跨部门删除、部门授权动态生效。

### 2.4 边界值

- 名称 1/2/50/51 字符；简介 200/201。
- 切片 max 64/4096、overlap 0/max/2、父 256/4096、子 64/父。
- TopK 1/100/101；TopN 1/20/21 且 > TopK。
- 阈值 0/0.3/1；文件名 255 字符；目录 5/6 层；批量 50/51 个；文件 100 MB/101 MB。
