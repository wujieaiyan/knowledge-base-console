# 04 · 接口设计

> 版本：v0.1　风格：REST + JSON　基础路径：`/api/v1`
> 关联：[数据模型](03-数据模型设计.md)、[解析切片与检索设计](05-解析切片与检索设计.md)

## 1. 通用约定

### 1.1 请求与响应

- 认证：登录态令牌或会话 Cookie，服务端解析出 `tenantId`、`userId`、`deptId`；客户端不得传用户身份。
- 响应统一包络：

```json
{
  "code": "0",
  "message": "OK",
  "data": {},
  "traceId": "0af7651916cd43dd8448eb211c80319c"
}
```

- 成功用 HTTP 2xx；业务失败使用对应 HTTP 状态 + 字符串错误码（见第 8 节）。
- ID 一律以字符串返回，避免前端精度丢失。
- 时间使用 ISO-8601 带时区：`2026-11-07T10:22:31+08:00`。
- 分页参数：`page`（从 1 开始，默认 1）、`size`（默认 20，最大 100）；响应：

```json
{ "items": [], "total": 128, "page": 1, "size": 20 }
```

- 局部更新使用 `PATCH`；配置类整体保存使用 `POST .../config-versions`（生成不可变版本）。
- 写操作支持 `Idempotency-Key`（创建/重试/重建），服务端保留 24 小时；同键不同请求体返回 `409 KB_40906`。
- 乐观锁：更新知识库基础信息时传 `If-Match: "<rowVersion>"`，冲突返回 `409 KB_40901`。

### 1.2 权限与可见性

| 操作级别 | 所需有效角色 |
| --- | --- |
| 读取（详情、列表、文档、任务、检索测试） | READER 及以上 |
| 维护（文档、目录、标签、文档级重建） | EDITOR 及以上 |
| 配置与成员（解析/切片/检索配置、成员、基础信息） | ADMIN 及以上 |
| 转让/删除知识库 | OWNER（平台管理员可删除） |

- 对“无任何权限”的知识库统一返回 `404`，避免探测；有权限但角色不足返回 `403`。
- 有效角色 = 个人授权 ∪ 部门授权，取最高。
- 部门成员接口仅返回当前用户可见组织范围，禁止跨部门枚举。

### 3.1 列表

```http
GET /api/v1/kb/series?scope=accessible&page=1&size=12&keyword=薪酬&deptId=1024&status=ACTIVE&sort=updatedAt,desc
```

| 参数 | 说明 |
| --- | --- |
| `scope` | `accessible`（默认）/ `maintainable` |
| `keyword` | 名称/简介模糊匹配 |
| `deptId` | 按所属部门过滤 |
| `status` | 存储状态；UI 的“部分异常”需传 `health=PARTIAL` |
| `health` | `NORMAL/PARTIAL`（P1） |
| `sort` | `updatedAt,desc`（默认）/ `name,asc` |

响应：

```json
{
  "code": "0",
  "message": "OK",
  "data": {
    "items": [
      {
        "id": "9001",
        "name": "薪酬制度问答",
        "description": "覆盖薪酬、社保与个税常见问题",
        "deptId": "1024",
        "deptName": "人力资源部",
        "authorId": "1001",
        "authorName": "张三",
        "status": "ACTIVE",
        "displayStatus": "NORMAL",
        "docCount": 128,
        "readyDocCount": 120,
        "failedDocCount": 3,
        "chunkCount": 18234,
        "indexStrategy": "HYBRID",
        "rowVersion": 12,
        "updatedAt": "2026-11-07T10:22:31+08:00"
      }
```

- `displayStatus=PARTIAL` 当 `failedDocCount > 0`，用于卡片“部分异常”徽标；“初始化中”由 `readyDocCount=0` 且存在运行中任务派生。
- 列表只返回当前用户有权的知识库；无权限的知识库不出现在计数中。

### 3.2 创建

```http
POST /api/v1/kb/series
Idempotency-Key: 5d1c2f0e-...
Content-Type: application/json
```

```json
{
  "name": "薪酬制度问答",
  "deptId": "1024",
  "description": "覆盖薪酬、社保与个税常见问题",
  "indexStrategy": "HYBRID",
  "draft": false,
  "config": {
    "parse": {
      "docTypes": ["PDF", "DOCX", "XLSX", "MD"],
      "perType": {
        "PDF": { "enabled": true, "strategy": "AUTO" },
        "DOCX": { "enabled": true, "strategy": "NATIVE" },
        "XLSX": { "enabled": true, "strategy": "NATIVE" },
        "MD": { "enabled": true, "strategy": "NATIVE" }
      },
      "ocr": { "languages": ["zh", "en"], "minConfidence": 0.6, "keepLayout": true },
      "options": { "tableStructure": true, "filterHeaderFooter": true, "ocrEmbeddedImages": false }
    },
    "chunk": {
      "strategy": "DEFAULT",
      "common": { "maxTokens": 512, "overlapTokens": 64, "minTokens": 50, "keepTableWhole": true, "tokenizer": "cl100k_base" }
    },
    "retrieval": {
      "hybridEnabled": true,
      "vectorWeight": 0.7,
      "rerankEnabled": true,
      "rerankModel": "default",
      "citation": { "enabled": true, "granularity": "PARAGRAPH" },
      "recallTopK": 20,
      "rerankTopN": 5,
      "similarityThreshold": 0.3,
      "noAnswerStrategy": "EMPTY"
    }
  }
}
```

响应 `201`：

```json
{
  "code": "0",
  "message": "OK",
  "data": {
    "id": "9001",
    "status": "ACTIVE",
    "configVersionId": "3001",
    "ownerMemberId": "7001"
  },
  "traceId": "..."
}
```

规则：

- 服务端在事务内创建知识库、配置版本 v1、根目录、owner 成员；失败整体回滚。
- `draft=true` 时状态为 `DRAFT`，仅创建者可见；发布接口为 P1。
- 同一 `Idempotency-Key` 重放返回首次结果。

### 4.1 保存配置并可选重建

```http
POST /api/v1/kb/series/9001/config-versions
If-Match: "12"
Idempotency-Key: 8b6f...
```

```json
{
  "indexStrategy": "HYBRID",
  "parse": { "...": "同上" },
  "chunk": {
    "strategy": "PARENT_CHILD",
    "common": { "maxTokens": 512, "overlapTokens": 64, "minTokens": 50, "keepTableWhole": true, "tokenizer": "cl100k_base" },
    "parentChild": { "parentTokens": 1024, "childTokens": 256, "childOverlap": 32, "maxChildrenPerParent": 8 }
  },
  "retrieval": { "...": "同上" },
  "changeNote": "切片改为父子结构",
  "rebuild": { "scope": "NONE" }
}
```

`rebuild.scope`：`NONE`（仅保存）/ `FULL`（全量）/ `FAILED`（仅失败文档，P1）。索引策略变更时仅允许 `NONE` 或 `FULL`。

响应 `201`：

```json
{
  "code": "0",
  "message": "OK",
  "data": {
    "configVersionId": "3002",
    "versionNo": 13,
    "rebuildTaskId": null
  },
  "traceId": "..."
}
```

- 校验失败返回 `422 KB_40002`，`details` 定位到字段。
- `If-Match` 不匹配返回 `409 KB_40901`，前端提示“配置已被他人修改，请刷新”。

### 4.2 重建

```http
POST /api/v1/kb/series/9001/rebuild

```

### 4.4 检索测试与生成（P1）

实现路径：`POST /kb/series/{id}/retrieval/test`。

```json
{
  "query": "年假怎么计算",
  "topK": 5,
  "threshold": 0.3,
  "hybrid": true,
  "rerank": true,
  "generate": true
}
```

- 使用“已保存的生效配置”；请求体可覆盖 `topK`（不超过配置上限）、阈值、混合检索、精排与是否生成，避免测试与线上口径漂移。
- `topK` 为空时使用配置的 `rerankTopN`；`generate` 默认 `true`。
- 检索测试页发送 `generate=false`；聊天页发送 `generate=true`。
- 检索优先走 Elasticsearch 向量 + BM25，不可用时回退本地 H2；生成调用 Ollama，失败时仍返回引用。

响应：

```json
{

  "message": "OK",
  "data": {
    "query": "年假怎么计算",
    "answer": "员工累计工作满 1 年不满 10 年的，年休假 5 天 [1]。",
    "noAnswer": false,
    "totalCandidates": 42,
    "returned": 1,
    "tookMs": 8569,
    "retrievalEngine": "ELASTICSEARCH",
    "hybrid": true,
    "rerank": true,
    "llmUsed": true,
    "llmModel": "qwen2.5:3b-instruct",
    "llmError": null,
    "retrievalTookMs": 69,
    "llmTookMs": 8500,
    "citations": [
      {
        "chunkId": 55001,
        "documentId": 12001,
        "documentName": "考勤规则.docx",
        "pageNo": 3,
        "titlePath": "考勤规则 > 年假 > 计算方式",
        "content": "员工累计工作满 1 年不满 10 年的，年休假 5 天……",
        "parentContent": null,
        "chunkLevel": "SINGLE",
```

- `retrievalEngine`：`ELASTICSEARCH` / `LOCAL`。

- 重试 `202` 返回新任务 ID；原任务不变。
- 重建/批量任务部分成功时，`failedItems` 返回失败对象清单（`documentId`、`errorCode`、`errorMessage`），任务状态仍为 `FAILED`。
- 取消 `202`，最终状态 `CANCELED`；取消为协作式，执行器在阶段边界检查取消标记并清理临时切片。
- SSE 事件：`event: task.updated`，`data: {taskId,status,progress,stage}`；连接 30 分钟自动断开重连。

## 9. 异步任务协议

1. **提交即返回**：上传、重建、删除清理返回 `202` + `taskId`；业务数据先落库，任务通过 outbox 投递。
2. **状态查询**：轮询 `GET /kb/tasks/{id}`，建议 1–2 s；或订阅 SSE。
3. **终态**：`SUCCEEDED` / `FAILED` / `CANCELED`；前端据此刷新文档/知识库。
4. **幂等**：同一 `Idempotency-Key` 只创建一个任务；执行器按 `(document_id, type, config_version_id)` 幂等处理，重复消费不产生重复切片。
5. **重试**：仅 `FAILED` 可重试；最多 3 次，退避 10 s / 60 s / 300 s；重试生成新任务并保留链路。
6. **取消**：仅 `QUEUED/RUNNING` 可取消；执行器在阶段边界响应，清理未提交的切片与向量。
7. **超时**：单任务默认 30 分钟，超时置失败并释放锁；大文件可通过类型配置上调。

## 10. 版本与兼容

- 所有接口以 `/api/v1` 开头；字段只增不删，删除字段至少保留一个小版本并标记 `deprecatedAt`。
- 枚举新增时前端需对未知值降级展示为“未知状态”，不得崩溃。
- 配置 JSON 由服务端做严格校验并回填默认值；前端不得依赖未知字段。
